
# Yapay Zeka CV Yazarı

Mesleğini yaz, Yapay Zeka sana profesyonel LinkedIn CV özeti yazsın.

## Özellikler
- ✅ Prompt Mühendisliği teknikleri kullanır
- ✅ Llama 3 LLM modeli ile çalışır 
- ✅ Türkçe, profesyonel ve başarı odaklı metin üretir
- ✅ 10 saniyede CV özeti

## Nasıl Çalıştırılır?
1. Gerekli kütüphaneyi kur: `pip install requests`
2. Ollama'ya Llama3'ü indir: `ollama pull llama3`
3. Uygulamayı çalıştır: `python main.py`
